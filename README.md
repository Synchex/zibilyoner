## ✨ Proje Hakkında

**Zibilyoner**, sıradan bir bilgi yarışması değil — bu bir **başyapıt**. 

Mehmet Can Büyüklü'nün önderliğinde, web'den mobil platforma taşınan bu proje, React Native ve Expo'nun gücünü kullanarak hem iOS hem de Android'de kusursuz bir deneyim sunuyor. Her satır kod, her piksel, her animasyon **ustalıkla** işlenmiş.

## 🎯 Özellikler

### 🧠 Zengin Soru Havuzu
- **826+ özgün soru** (645 Türkçe, 181 İngilizce)
- Akıllı **duplikasyon önleme** sistemi
- **5 ana kategori**: Genel Kültür, Spor, Tarih, Bilim, Sanat

### 🏅 Spor Alt Kategorileri
- ⚽ Dünya Futbolu
- 🇹🇷 Türk Futbolu  
- 🏀 Basketbol
- 🏆 Türk Sporları
- ⭐ Efsaneler & Rekorlar

### 📜 Tarih Alt Kategorileri
- 🏛️ Türk Tarihi (Osmanlı, Selçuklu, Cumhuriyet)
- 🌍 Modern Tarih (Dünya Savaşları)
- 🏺 Antik Anadolu Uygarlıkları
- 🎲 Karışık

### 💰 Ödül Sistemi
- **12 soruluk** merdiven sistemi
- YUAN para birimi ile gerçekçi ekonomi
- Günlük kredi yenileme
- İkinci şans modal'ı

### 🌐 Çok Dilli Destek
- 🇹🇷 Türkçe
- 🇬🇧 İngilizce
- Anlık dil değişimi

## 🚀 Kurulum

```bash
# Repoyu klonla
git clone https://github.com/Synchex/zibilyoner.git

# Dizine gir
cd zibilyoner

# Bağımlılıkları yükle
npm install

# Uygulamayı başlat
npx expo start
```

## 📱 Çalıştırma

```bash
# iOS Simülatör
npx expo start --ios

# Android Emülatör
npx expo start --android

# Web (geliştirme)
npx expo start --web
```

## 🏗️ Teknoloji Yığını

| Teknoloji | Kullanım |
|-----------|----------|
| **Expo SDK 53** | Cross-platform geliştirme |
| **React Native** | Mobil UI framework |
| **TypeScript** | Tip güvenliği |
| **React Navigation** | Sekme & stack navigasyon |
| **AsyncStorage** | Kalıcı veri depolama |
| **Expo Linear Gradient** | Premium görsel efektler |
| **Ionicons** | İkon kütüphanesi |

## 📁 Proje Yapısı

```
src/
├── components/          # Yeniden kullanılabilir bileşenler
│   ├── modals/         # Modal bileşenleri
│   ├── CircularTimer   # Dairesel zamanlayıcı
│   ├── PrizeLadder     # Ödül merdiveni
│   └── ProgressBar     # İlerleme çubuğu
├── context/            # React Context providers
│   ├── CreditContext   # Kredi yönetimi
│   ├── YuanContext     # Para birimi
│   ├── GameHistoryContext # Oyun geçmişi
│   └── LanguageContext # Dil yönetimi
├── data/               # Veri katmanı
│   ├── seeds/          # Soru JSON'ları
│   ├── questionBank    # Soru havuzu mantığı
│   └── translations    # Çeviriler
├── screens/            # Uygulama ekranları
└── styles/             # Tema & tasarım tokenleri
```
